# 구현 및 검증 기록

## 구현 단계

1. Windows x64에 Python 3.12.10과 프로젝트 가상 환경을 구성했습니다. Showdown GIF를 다운로드하고 형식, 프레임 수, 알파 채널을 확인했습니다.
2. PySide6 투명 도구 창, QMovie, 픽셀아트 확대, 자동 이동과 방향 반전, 작업 영역 경계 처리를 구현했습니다.
3. 클릭·드래그 구분, 클릭 간격 제한, 한국어 메뉴와 효과를 연결했습니다. 수치 변화, 수면 회복, 레벨업 규칙은 모델에 모았습니다.
4. 상태창, 설정창, 시스템 트레이를 연결했습니다. JSON을 원자적으로 교체하고 직전 유효본을 백업하도록 했습니다. QLockFile로 동시 실행을 막습니다.
5. Windows에서 소스 앱을 실행해 데스크톱 테스트를 반복했고, PyInstaller로 콘솔 없는 x64 단일 실행파일을 빌드했습니다.

## 오류와 수정

- 샌드박스 임시 디렉터리에서 pytest가 테스트 폴더를 생성하지 못했습니다. 작업 폴더의 `build/pytest`를 지정해 해결했습니다.
- 투명 클릭 테스트에서 뒤 창이 다른 창에 가려져 잘못된 결과가 나왔습니다. 뒤 창을 펫과 같은 최상위 창 그룹에 두고 투명·불투명 픽셀을 각각 검사했습니다.
- 초기 EXE에서 `QtCore` 로딩이 실패했습니다. 진단 빌드와 번들 목록에서 Visual C++ 런타임 버전 혼재 및 작업 환경의 Poppler ICU DLL이 번들에 들어온 것을 확인했습니다. 재현 환경에서 PySide6 6.8.3을 고정하고, Qt 런타임을 사용하며 외부 ICU를 제외하도록 빌드를 수정했습니다.
- PySide6 6.8.3의 `QLockFile.tryLock`에는 시간 제한 인수가 필요했습니다. `0`을 명시해 중복 실행 시 즉시 종료하도록 수정했고, 별도 프로세스를 띄우는 회귀 테스트를 추가했습니다.
