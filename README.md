# 포켓몬·디지몬 데스크톱 펫

Windows 화면에서 포켓몬과 디지몬을 여러 마리 돌보는 개인 학습용 앱입니다.

## 실행

[Windows x64 공통 크기 버전](dist/DesktopPet-SharedSize.exe)을 실행합니다. Python과 인터넷 연결 없이 기본 기능을 사용할 수 있습니다. 트레이 아이콘을 우클릭하면 숨겨진 피카츄를 다시 표시하거나 앱을 종료할 수 있습니다.

- **클릭**하면 하트와 말풍선이 나타나고 행복도와 경험치가 증가합니다.
- **드래그**하면 원하는 작업 영역으로 옮깁니다.
- **우클릭**하면 식사, 놀이, 쓰다듬기, 수면, 상태, 설정 메뉴가 열립니다. **기술 사용**을 고르면 피카츄가 전기를 모으면 바라보는 방향의 앞쪽 바닥으로 번개가 떨어집니다.
- **우클릭 → 크기 조절**에서 빠르게 크기를 바꿀 수 있습니다. 설정창에서는 64~240 px 사이의 크기를 직접 입력할 수 있습니다. 변경한 크기는 모든 친구에 즉시 적용되고, 새로 선택하는 친구와 다음 실행에도 유지됩니다.
- **자동 이동**이 켜져 있으면 피카츄가 걷는 사이에 가끔 혼자 뛰며 놉니다.
- **설정**에서 크기, 속도, 자동 이동, 항상 위, 말풍선, 효과음, 시작 시 자동 실행, 전체 화면 감지를 변경할 수 있습니다.

종료 중에는 수치가 감소하지 않습니다. 데이터는 `%LOCALAPPDATA%\PikachuDesktopPet\pet.json`에 보존되며 같은 폴더의 `pet.backup.json`으로 복구할 수 있습니다.

## 시작 친구와 뽑기

첫 실행 시 파이리, 꼬부기, 이상해씨, 아구몬, 파피몬 중 한 마리를 랜덤으로 받습니다. 나머지 친구는 배틀타워에서 골드를 모은 다음 **우클릭 → 친구 뽑기…**로 해금할 수 있습니다.

| 항목 | 골드 또는 확률 |
| --- | --- |
| 층 첫 승리 | 40 + 층 × 2 골드 |
| 클리어한 층 승리 | 16 + 층 ÷ 2 골드, 소수점 버림 |
| 1회 뽑기 | 120골드 |
| 미진화 / 1단계 / 2단계 / 3단계 이상 | 70% / 22% / 7% / 1% |
| 중복 | 60골드 환급, 강화 +1 |

뽑은 포켓몬은 몬스터볼에서, 디지몬은 디지바이스에서 등장합니다. 등장 연출 뒤 새 친구 또는 중복 보상을 확인할 수 있습니다.

확률은 진화 단계 묶음에 적용되고, 해당 묶음 안에서 한 마리가 균등하게 선택됩니다. 강화 +1마다 배틀 HP +2, 공격 +1, 방어 +1을 받습니다. 골드는 배틀 승리와 일일 퀘스트로 획득하는 게임 재화입니다.

기존 버전에서 업데이트해도 타워 진행과 각 친구의 육성 기록이 보존됩니다. 시작 친구 외 기존 친구는 뽑기로 다시 획득하면 기존 레벨과 설정으로 이어집니다.

## 일일 퀘스트

펫이나 트레이를 **우클릭 → 일일 퀘스트…** 하면 오늘의 진행도를 볼 수 있습니다. 여러 친구를 돌본 횟수를 합산하며 보상은 목표 횟수에 도달하면 자동으로 지급됩니다. PC 현지 시간의 자정에 새 퀘스트가 열립니다.

| 직접 돌보기 | 보상 |
| --- | --- |
| 밥 주기 3회 | 35골드 |
| 같이 놀기 2회 | 35골드 |
| 쓰다듬기 3회 | 20골드 |
| 하루 합계 | 90골드 |

## 여러 친구 돌보기

1. 바탕화면의 펫이나 트레이 아이콘을 우클릭하고 **친구 선택…**을 엽니다.
2. 포켓몬이나 디지몬을 검색하고 함께 돌볼 친구를 모두 체크한 뒤 **적용**을 누릅니다.
3. 각 친구의 우클릭 메뉴에서 밥을 주거나 **기술 사용**을 선택합니다.

목록에는 포켓몬 1,025종과 폼을 합쳐 1,366개, 디지몬 스프라이트 233개가 있습니다. 보유한 친구 여러 마리를 선택할 수 있습니다. 기본 포함 이미지 이외의 스프라이트는 처음 선택할 때 Showdown에서 받아 로컬에 저장합니다. 선택을 해제한 친구의 육성 데이터는 다시 선택하면 복원됩니다.

## 배틀타워

출전할 펫을 우클릭한 뒤 **배틀타워 → N층 도전**을 고릅니다. 상대가 펫 옆 바탕화면에 나타나 자동 전투가 진행됩니다. HP와 결과는 캐릭터 위에 표시됩니다. 승리하면 다음 층이 열리고, 이미 이긴 층에는 **클리어한 층** 메뉴에서 다시 도전할 수 있습니다. **자동 사냥 시작**을 고르면 현재 해금된 층부터 연속 도전합니다. 승리 후 다음 층으로 넘어가며 100층에서는 반복 도전합니다. 패배하거나 **자동 사냥 중단**을 고르면 종료됩니다.

상대 진화 단계는 1~25층 0단계, 26~50층 1단계, 51~75층 2단계, 76~100층 3단계입니다. 상대 레벨도 층이 오를수록 증가합니다. 돌보기와 배틀 경험치로 펫의 레벨을 올리면 배틀 HP·공격·방어가 증가합니다. 같은 레벨에서도 진화 단계가 높은 종은 단계 보너스를 받습니다.

배틀의 HP는 입장할 때마다 가득 차며, 육성 화면의 체력과 별도로 계산합니다. 타워 진행은 계정 공용이고 승리 경험치는 출전한 친구에게 지급됩니다. 현재 출전 친구의 진화 단계는 선택한 종이나 폼을 기준으로 계산합니다.

## 야생 출현과 포획

깨어 있는 파트너가 바탕화면에 보이면 1~10분의 무작위 간격으로 야생 포켓몬이나 디지몬을 만날 수 있습니다. 야생 친구는 바탕화면에서 움직이고 파트너와 자동으로 싸웁니다. 야생 HP가 40% 이하가 되면 전투가 멈추고, 15초 안에 야생 캐릭터를 직접 클릭해 한 번 포획을 시도할 수 있습니다.

미진화는 75%, 1단계는 60%, 2단계는 45%, 3단계 이상은 30%의 포획 확률을 적용합니다. 성공한 친구는 **친구 선택…**에서 불러올 수 있습니다. 야생 출현은 배틀타워에 이미지가 포함된 100종 중 아직 보유하지 않은 친구를 대상으로 합니다. 별도로 받은 스프라이트가 없는 포획 친구는 기본 포함 정적 이미지로 오프라인에서도 표시됩니다.

## 아구몬 애니메이션 시범 적용

아구몬을 선택하면 상태마다 프레임 재생 순서와 속도가 바뀝니다. 기존 Showdown GIF의 픽셀과 원본 팔레트를 사용하며, 캐릭터의 비율을 유지하고 발 위치를 기준으로 그립니다. 다른 디지몬의 프로필은 `assets/animation_profiles.json`에 키, 프레임 순서, 프레임 간격, 하단 접지 좌표를 추가하는 방식으로 확장할 수 있습니다.

## 소스 실행 및 빌드

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

```powershell
.venv\Scripts\python.exe -m pytest -q --basetemp build/pytest
.\build.bat
.venv\Scripts\python.exe tests/windows_exe_smoke.py
```

빌드 결과는 `dist\PikachuDesktopPet.exe`에 저장됩니다. 네이티브 창 테스트에는 Windows 대화형 데스크톱이 필요합니다.
